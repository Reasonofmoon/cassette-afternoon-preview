- 모바일 세로 읽기, 페이지 넘김, 대본 보기
- 전체 이어듣기, 페이지별·컷별 듣기와 따라가기

## 구조와 배포
index.html, reader.js, style.css, story.json은 편집 가능한 리더 소스입니다. site.zip은 그림·음원·글꼴을 포함한 정적 사이트 묶음입니다. GitHub Actions가 묶음을 _site에 풀고 루트의 최신 리더 소스를 적용하여 GitHub Pages로 배포합니다.

원문 전문이 아닌 40컷 각색본입니다. 원문의 불확실한 기억과 멈춘 결말을 유지하며 정란의 새 음성이나 해결 장면을 추가하지 않았습니다. 생성형 이미지·합성 음성 사용. 세부 그림과 발음·연기의 최종 사람 청취·감수는 별도입니다.

글꼴 저작권 및 SIL OFL은 fonts에 포함했습니다. 이미지·음원·서사 발췌에 포괄적인 오픈소스 라이선스를 부여하지 않습니다. 원문 전체·내부 스킬·제작 메모·계정 기록은 포함하지 않습니다.
